# 보이스아이 (VoiceEye)

DAL&Co.의 회의 접근성 MVP입니다. 청각장애인이 소규모 대면회의에서 대화를 읽고, 작성한 문장을 음성으로 전달하며, 놓친 구간을 확인하는 흐름을 시험합니다.

## 발표장 시연

`portable/voiceeye-demo/index.html`을 Chrome 또는 Edge로 엽니다. 인터넷 연결, Node.js 설치, API 키가 필요하지 않습니다.

`회의 시연 시작`을 누르면 다섯 명이 앉은 회의실 이미지 위에서 발언자 표시와 자막이 움직입니다. 80초 동안 회의 시작, 안건 제시, 동시 발언 확인, 비공개 작성, 음성 발언, 결정 확인이 이어집니다. 시연용 합성 음성 파일이 포함되어 있어 기본 시연에는 한국어 음성 설치도 필요하지 않습니다.

패널 아래에는 확정된 발언이 쌓이고 `텍스트 저장`으로 내려받을 수 있습니다. 오른쪽 `내 발언`에서 문장을 작성하고 `문장 확인` → `음성으로 말하기`를 누르면 실제 기기 내 한국어 TTS로 재생합니다. 끝까지 재생된 문장만 키보드 발언으로 기록합니다. 중지한 발언과 비공개 미리보기는 완료 기록에 넣지 않습니다.

`마이크 자막`은 실제 브라우저 STT입니다. 좌석을 수동으로 선택하거나 화자 미확정으로 기록합니다. 직접 입력한 문장의 음성 재생에는 기기 내 한국어 음성이 필요하며, 실제 마이크 입력은 브라우저 지원·권한·연결 상태에 따라 달라집니다.

시연은 대본으로 움직입니다. 좌석·겹침·자막 문장은 실제 마이크나 실시간 화자 판정 결과가 아닙니다.

## 개발 실행

Node.js 22.18 이상을 사용합니다.

```bash
npm ci
npm run dev
```

| 경로 | 내용 |
| --- | --- |
| `/` | 회의실 이미지·80초 시연·실제 마이크 자막·입력 문장 TTS·텍스트 기록 |
| `/lab` | 실제 브라우저 STT, 비공개 작성, 확인 후 TTS 재생·중지 점검 |
| `/strategy` | 제품·AI 전략 |
| `/plan` | 기존 사업계획 자료 |
| `/bench` | 저장된 기준선 자료. 현재 마이크 MVP 성능과 구분 |

`app-env.json`은 공개 빌드 플래그만 담고 Auth OFF를 유지합니다. 데이터베이스는 사용하지 않습니다.

기본 TTS는 `localService === true`인 기기 내 한국어 음성만 사용합니다. 해당 음성이 없으면 기능 점검 화면에 안내합니다. 발언 중지 시 완료 기록을 남기지 않으며, 이미 재생된 음성까지 되돌릴 수는 없습니다.

브라우저 STT는 별도 API 키가 없어도 사용할 수 있지만, 처리 위치는 브라우저 정책과 기기 지원에 따라 달라집니다. faster-whisper 비교, 자막 공백 탐지, 익명 방향 추정은 본선 개발 대상입니다. 실제 마이크 인식률·지연·TTS 자연스러움은 아직 실측하지 않았습니다.

## 검증

```bash
npm run test:mvp
npm run typecheck
npm run build
npm run build:demo
```

31개 시험을 포함합니다. STT 7개, 기존 TTS 9개, 새 입력창 7개, 자막·기록·음성 파일 6개, 시나리오·휴대용 HTML 2개입니다. 음성 API를 대체한 회귀시험과 파일 검사이며 실제 회의 성능 검증과 구분합니다.

휴대용 HTML도 같은 React 화면에서 `npm run build:demo`로 생성합니다. 사진·합성 음성·CSS·프로그램이 하나의 파일에 들어갑니다. `npm run demo:serve`는 이 파일을 `http://127.0.0.1:8081/`에서 점검하는 개발용 명령입니다. 시연 음성을 다시 만들려면 한국어 음성이 설치된 Windows에서 `powershell -NoProfile -File scripts/generate-demo-audio.ps1`을 실행합니다.

## 기존 기획 자료

예산 원본은 `src/data/plan-v2.ts`입니다. 인용 11건은 미검증 상태입니다.

```bash
npm run docs:sync
npm run check:plan
```

투명 패널은 가독성과 호환성을 확인할 확장안입니다. 실물 패널, 카메라 융합, 스마트글래스가 완성됐다고 소개하지 않습니다.

조직 저장소에서는 push로 Pages가 자동 공개 배포되지 않습니다. 공개 배포가 필요하면 최종 검토 후 워크플로를 수동 실행합니다. 과거 공개 데모는 이 저장소의 최신 코드와 다를 수 있습니다.

## 행사 준비 회의 발표판 (2026-09-16)

발표판은 `portable/neural`에 있다. Windows 기본 음성 대신 USB에 포함한 Supertonic 2 한국어 TTS를 사용한다. 참석자 발언 음성 재생이 끝난 뒤 Whisper base가 인식한 결과를 자막에 표시한다. 손들기와 키보드 발언은 회의 진행을 멈춘다. 이전 React MVP의 마이크 구현은 보존했다.

`npm run setup:demo:neural` → `npm run build:demo:neural` → `npm run demo:neural`. 검사: `npm run test:demo:neural`. 모델의 이용조건과 구현 한계는 `portable/neural/README.md`를 확인한다. 개발용 서버와 USB 실행 파일은 로컬 파일 제공 용도이며 모델 추론은 브라우저 안에서 수행한다.
