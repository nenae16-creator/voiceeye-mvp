# 보이스아이 (VoiceEye)

DAL&Co.의 회의 접근성 MVP입니다. 청각장애인이 소규모 대면회의에서 대화를 읽고, 작성한 문장을 음성으로 전달하며, 놓친 구간을 확인하는 흐름을 시험합니다.

## 발표장 시연

`portable/voiceeye-demo/index.html`을 Chrome 또는 Edge로 엽니다. 인터넷 연결, Node.js 설치, API 키가 필요하지 않습니다.

`회의 시연 시작`을 누르면 80초 동안 회의 시작, 안건 제시, 동시 발언 확인, 비공개 작성, 음성 발언, 결정 확인이 이어집니다. 한국어 TTS가 없는 기기에서는 화면 시연만 진행됩니다.

시연은 대본으로 움직입니다. 좌석·겹침·자막 문장은 실제 마이크나 실시간 화자 판정 결과가 아닙니다.

## 개발 실행

Node.js 22.18 이상을 사용합니다.

```bash
npm ci
npm run dev
```

| 경로 | 내용 |
| --- | --- |
| `/` | 80초 발표 시연 |
| `/lab` | 실제 브라우저 STT, 비공개 작성, 확인 후 TTS 재생·중지 점검 |
| `/strategy` | 제품·AI 전략 |
| `/plan` | 기존 사업계획 자료 |
| `/bench` | 저장된 기준선 자료. 현재 마이크 MVP 성능과 구분 |

`app-env.json`은 공개 빌드 플래그만 담고 Auth OFF를 유지합니다. 데이터베이스는 사용하지 않습니다.

기본 TTS는 `localService === true`인 기기 내 한국어 음성만 사용합니다. 해당 음성이 없으면 기능 점검 화면에 안내합니다. 발언 중지 시 완료 기록을 남기지 않으며, 이미 재생된 음성까지 되돌릴 수는 없습니다.

브라우저 STT는 별도 API 키가 없어도 사용할 수 있지만, 처리 위치는 브라우저 정책과 기기 지원에 따라 달라집니다. faster-whisper 비교, 자막 공백 탐지, 익명 방향 추정은 본선 개발 대상입니다. 실제 마이크 인식률·지연·TTS 자연스러움은 아직 실측하지 않았습니다.

## 검증

```bash
npm run test:mvp
npm run typecheck
npm run build
```

STT 시험 7개, TTS 시험 9개, 발표 시나리오·휴대용 HTML 시험 2개를 포함합니다. 음성 API를 대체한 회귀시험이며 실제 회의 성능 검증과 구분합니다.

## 기존 기획 자료

예산 원본은 `src/data/plan-v2.ts`입니다. 인용 11건은 미검증 상태입니다.

```bash
npm run docs:sync
npm run check:plan
```

투명 패널은 가독성과 호환성을 확인할 확장안입니다. 실물 패널, 카메라 융합, 스마트글래스가 완성됐다고 소개하지 않습니다.

조직 저장소에서는 push로 Pages가 자동 공개 배포되지 않습니다. 공개 배포가 필요하면 최종 검토 후 워크플로를 수동 실행합니다. 과거 공개 데모는 이 저장소의 최신 코드와 다를 수 있습니다.
