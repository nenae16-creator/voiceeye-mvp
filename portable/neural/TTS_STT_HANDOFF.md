# VoiceEye MVP 음성·자막 인수인계 — 2026-09-16 수정

사용자는 현재 목소리는 괜찮다고 확인했고 자막 오인식을 수정해 달라고 요청했다. 목소리를 이전 Windows 기본 음성으로 되돌리지 않는다.

## 현재 TTS
- Supertonic 2 한국어 신경망 TTS를 브라우저의 ONNX Runtime WASM으로 실행한다.
- F1·F2·M1·M2 음색을 사용한다. rate·pitch만 바꾼 동일 Windows 음성이 아니다.
- 발언 텍스트를 한국어로 합성하고 PCM을 재생한다. 외부 API·키·유료 호출이 없다.
- speechSynthesis / SpeechSynthesisUtterance / Heami는 교체 전 구현이다. 현재 발표판의 엔진 설명으로 쓰지 않는다.

## 현재 STT
- 자막은 별도 모델 Whisper small q8이 처리한다. 기존 Whisper base를 교체했다.
- 실제 재생한 PCM만 16kHz로 변환해 인식한다. 입력 대본을 정답 자막으로 표시하거나 오인식을 몰래 덮지 않는다.
- 한국어 전사이며 번역이 아니다. 발언이 끝난 뒤 인식하는 구간 방식이다.
- 자막 오인식 수정 요청을 TTS 엔진 변경으로 해결했다고 설명하지 않는다.
- 사용자 키보드 발언은 이미 작성한 원문을 TTS에 전달하고 원문을 기록한다.

## 유지할 동작
금요일 고용 상담 행사의 준비물 회의. 한 명씩 발언. 손들기를 누르면 발언하겠습니다 음성으로 차례 요청. 초안·입력·발언 차례·음성 처리 중 다음 발언 차단. 발언 마치기 이후에만 진행 재개. 마이크·카메라 화자 판정을 구현했다고 설명하지 않는다.

## 소스·실행
소스: portable/neural/speech-worker.js, main.js, meeting-controller.js.
개발: npm run setup:demo:neural → npm run build:demo:neural.
발표장: USB 전체 폴더를 복사하고 시연시작.bat 실행. 음성 모델과 Node 실행 파일을 포함하며 별도 설치나 인터넷이 필요하지 않다. HTML 단독 더블클릭은 모델을 로딩하지 못한다.

## 확인 범위
같은 합성 음성 파일로 base와 small을 비교했다. base의 5 후 2시가 small에서 오후 2시로 인식되었다. 이 한 파일 결과를 실제 회의 전체 정확도나 100% 인식으로 표현하지 않는다. 큰 모델은 USB 용량과 초기 로딩·메모리 부담이 늘어난다.
