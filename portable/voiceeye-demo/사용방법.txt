VoiceEye 회의실 MVP · 2026-09-16

실행
1. ZIP을 풀고 이 폴더를 USB에 복사합니다.
2. 발표장 컴퓨터에서 index.html을 Chrome 또는 Edge로 엽니다.
3. F11로 전체 화면을 켜고 '회의 시연 시작'을 누릅니다.

회의 시연
다섯 명이 앉은 회의실 이미지에서 발언자의 좌석 테두리가 켜집니다.
합성 음성 파일이 재생되면서 자막이 나타나고, 확정된 문장은 패널 아래 기록에 쌓입니다.
겹침 예시에서는 두 좌석과 두 문장을 따로 표시합니다.
80초 시연은 인터넷, Node.js, API 키, 한국어 음성 설치 없이 실행됩니다.

내 발언
오른쪽 입력창에 문장을 쓴 뒤 '문장 확인'을 누릅니다.
내용을 읽고 '음성으로 말하기'를 누르면 실제 기기 내 한국어 음성으로 재생합니다.
끝까지 재생된 문장만 '키보드 발언'으로 기록합니다.
발언 중지와 작성 중인 문장은 완료 기록에 넣지 않습니다.
이 기능에는 컴퓨터에 설치된 한국어 음성이 필요합니다.
한국어 음성이 없으면 안내가 표시됩니다. 임의의 다른 언어 음성으로 대체하지 않습니다.

회의 기록
패널 아래 '텍스트 저장'을 누르면 현재 기록을 TXT 파일로 내려받습니다.
기록은 화면을 새로고침하거나 닫으면 사라집니다. 필요한 기록은 먼저 저장합니다.
대본 시연, 마이크 자막, 키보드 발언을 구분해 저장합니다.

실제 마이크
'마이크 자막'은 브라우저 STT를 사용합니다. 발언자의 좌석은 직접 선택합니다.
브라우저의 지원 여부, 마이크 권한, 네트워크 정책에 따라 동작합니다.
파일을 직접 여는 환경에서 마이크가 지원되지 않으면 발표는 기본 회의 시연으로 진행합니다.

발표 전
스피커 음소거와 출력 장치를 확인합니다.
기본 회의 시연 음성을 한 번 재생하고, 직접 입력한 문장의 음성도 별도로 확인합니다.

시연의 범위
회의실은 예시 이미지이며 참석자들은 실제 시험 참여자가 아닙니다.
회의 음성은 Windows 한국어 TTS로 만든 합성 음성입니다.
기본 시연 자막과 발언 위치는 대본입니다. 실제 마이크 인식·자동 화자 판정 성능으로 소개하지 않습니다.
