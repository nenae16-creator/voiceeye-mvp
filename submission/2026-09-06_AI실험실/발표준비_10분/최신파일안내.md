## 최신 MVP

소스는 저장소 루트의 portable/neural에 있습니다. Supertonic 2 한국어 TTS, Whisper small 음성 인식, 손들기와 키보드 발언, 명시적인 용어 보정을 사용합니다.

개발 PC에서 npm ci, npm run setup:demo:neural, npm run build:demo:neural 순서로 준비합니다. 실행은 npm run demo:neural입니다. 자세한 조건과 한계는 portable/neural/README.md에 있습니다.

이 폴더에 있던 VoiceEye_발표용_MVP_USB.zip은 이전 시연본입니다. 최신 신경망 모델을 포함한 배포본은 빌드·패키징 스크립트로 생성합니다. 대용량 모델과 Windows 실행 파일은 Git 소스에 넣지 않았습니다. 모델은 고정 revision에서 다운로드하고 SHA-256 목록으로 확인합니다.
