## 실행 검증

- `npm run test:mvp`: 31개 통과. STT 7, 기존 TTS 9, 새 입력창 7, 자막·기록·음성 파일 6, 시나리오·HTML 2.
- `npm run typecheck`: exit 0.
- `npm run build`: exit 0. DB 연결 설정이 없어 마이그레이션은 건너뜀.
- `npm run build:demo`: 사진과 시연 음성을 포함한 단일 HTML 생성.
- 브라우저에서 비공개 문장 확인, 실제 TTS 재생 시작, 재생 완료 뒤 키보드 발언 기록을 확인했다.
- 휴대용 화면에서 80초 종료 뒤 대본 발언 7개, 직접 입력한 문장 재생 완료 뒤 기록 8개를 확인했다.
- `텍스트 저장`을 눌러 Downloads의 `VoiceEye_회의기록.txt` 생성과 731바이트 파일을 확인했다.
- 작은 화면(390×844)과 기본 데스크톱 화면에서 가로 넘침이 없었다. 휴대용 화면의 브라우저 오류·경고 로그는 0개였다.
- 중지 후 늦은 완료 콜백, 언마운트, 재생 오류, 이중 클릭, 한국어 IME 조합, 원격 음성 대체 방지는 콜백 시험으로 확인했다.

## 구현 범위

기본 80초 회의는 합성 음성과 저장된 대본을 사용한다. 화자 표시와 겹침 구간은 시연 데이터다. 사진 속 인물은 실제 시험 참여자가 아니다. 얼굴 신원 식별·자동 화자 판정을 구현했다고 설명하지 않는다.

실제 마이크 모드는 브라우저 STT이며 좌석을 수동으로 선택한다. 실제 마이크 입력→인식 결과의 이번 현장 성능은 측정하지 않았다. 인식률·지연·음성 자연스러움 수치는 제시하지 않는다.

직접 입력한 문장은 기기 내 한국어 TTS로 재생한다. 기기 내 음성이 없으면 안내하며 원격 음성으로 전환하지 않는다. 발언 중에는 마이크 자막을 중단한다. 부분 재생된 발언을 완료 기록에 넣지 않으므로 이미 전달된 일부 내용은 필요한 경우 따로 남겨야 한다.

기록은 현재 화면 메모리에 있으며 새로고침하면 초기화된다. 장기 보관은 TXT 저장으로 한다. 녹취·녹화와 자동 요약을 이번에 추가하지 않았다.

## 발표용 파일

`VoiceEye_발표용_MVP_USB.zip`을 풀고 `index.html`을 Chrome 또는 Edge로 연다. 기본 시연에는 인터넷·설치·API 키가 필요 없다. 직접 입력하는 음성은 한국어 음성이 설치된 PC에서 별도로 시험한다. 마이크는 브라우저 지원과 권한·네트워크 정책에 따라 동작한다.

이번 수정은 MVP 화면과 휴대용 시연 파일을 대상으로 했다. 제출 PPT를 새로 작성하거나 제출하지 않았다.
