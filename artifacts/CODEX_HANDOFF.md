# Codex 인수인계 프롬프트 — 보이스아이 (VoiceEye)

## 2026-09-04 사용자 결정 — 이 절이 아래의 글래스 주 플랫폼 지시보다 우선한다

회의실 주 플랫폼은 **노트북 위 데스크형 투명 자막 패널**로 전환했다. 노트북은 비공개 발언 초안·수정·운영 화면, 투명 패널은 확인된 공개 자막·발언자 좌석 방향 화면이다. 스마트글래스는 이동형 후속 옵션이다. 직접 투명 패널과 광학 콤바이너를 모두 검토하며 양면 좌우반전·밝기·시야각·안전·KC·복수 견적을 통과한 방식을 채택한다. 예산 총액 50.0억, 기기가액 1,138,000원, 80% 지원율 가정과 검산 6항은 유지한다. 현재 구현·데이터·문서는 `src/data/plan-v2.ts`, `src/data/product-policy.ts`, `npm run docs:sync` 결과를 우선한다.

아래 블록을 Codex에 **그대로 붙여넣으면** 이 프로젝트를 이어받을 수 있다.
작성일: 2026-09-03. 작성 주체: Grok Build. 제품 언어: 한국어.

## 붙여넣을 프롬프트 (복붙 시작)

```
너는 이 저장소의 유일한 후속 엔지니어다. 보이스아이(VoiceEye)를 이어서 완성한다.

역할: 청각장애인 회의접근성 20년급 실무 + 시스루 글래스 HUD + 한국어 스트리밍 ASR + 정부 예산 심의 대응. 추측으로 정책을 뒤집지 마라. 아래 결정을 기본값으로 고정하고, 바꿀 때는 이유를 문서와 UI에 동시에 반영하라.

============================================================
0. 한 줄 정의
============================================================
청각장애인이 공공·직장 회의에 참여하기 위한 시스루 글래스 HUD.
다른 사람 말 → 시야 자막 + 누가 말하는지 얼굴에 시각표시.
착용자 말 → 블루투스 키보드 입력 → 렌즈 미리보기 → 확인 후에만 스피커 TTS.
수어통역의 대체가 아니라 보완. 장애인 전용 디자인(낙인) 금지.

데모 앱(이미 있음) + 사업계획 v2(심의용) + ASR 실측 벤치가 한 제품이다.

============================================================
1. 절대 되돌리지 말 것 (v2 심의 전제)
============================================================
- 주 플랫폼 = 국내 KC 인증 + 화면 전 영역 제어 가능 시스루 글래스.
  Meta Ray-Ban Display는 조건부 옵션일 뿐 주 플랫폼이 아니다.
  KC 미인증 기기는 국가 보급 불가. 개인 직구 예외는 보급에 적용 안 됨.
- 화자 표시 기본값 = 세션 한정 익명 클러스터(화자 1~5). 얼굴·음성 임베딩
  신원 매칭은 기본값이 아니다. 주최자가 「이름 붙이기」로만 명단을 올린다.
- TTS는 렌즈 미리보기 → 확인 → 스피커. 미리보기 없이 바로 나가지 않는다.
- 기본 비저장. HUD에 「비저장」 표시. 제3자 고지(LED 등) 원칙 유지.
- 신뢰도 낮은 발화 = 점선 헤일로 + 자막 경고. 오판을 숨기지 않는다.
- 화자 인식 실패 시 이름을 고정하지 않고 방향만 표시로 격하.
- 요약에서 원문 미연결 문장 금지(환각 차단).
- 얼굴 박스 금지. 색 링 + 이름표 + 미니맵.
- 카피에서 「클로드급」「Claude」 금지. 엔진 표기는 실제 쓰는 모델명.
- 예산 숫자를 고치면 검산표 여섯 항목을 다시 맞춰라. v1은 검산 실패로 죽었다.
  총사업비 50.0억 = 국비 32.4 + 지방 8.0 + 민간 9.6.
  연차 2028 6.0 + 2029 16.0 + 2030 28.0 = 50.0.
  보급 1,500대 × 기기가액 1,138,000 × 지원율 80%.
  사업기간 2028–2030, 사전기획 2026.4Q–2027.
- 부록 11개 인용은 검증 전이다. 확정 사실처럼 쓰지 마라.

============================================================
2. 원 요구사항 (사용자)
============================================================
1. 청각장애인 대상
2. 회의 중 소리를 인지하지 못함
3. 글래스가 소리를 인지해 눈앞에 텍스트
4. 누가 발언하는지 시각 표시 (다중회의)
5. 착용자 발언은 BT 키보드 → 스피커 TTS
6. 언어·텍스트·음성이 안정적으로 나와야 함
7. 정부 예산에 맞출 것
8. 프로젝트를 완성할 것

후속: 한국어 회의체 ASR 최적화, 스트리밍 지연 최적화, 실제 인식률 확인,
STT 모델 명시, 다중 화자 시각표시, 사업계획 v2 반영, 빈 배경 금지·실제 사람 배치.

============================================================

============================================================

HUD 동작
- 기본 라벨 = 화자 N. 「이름 붙이기」 → 김서연/박민준/이하늘/최도윤/정유진
- 발언 중 = 굵은 색 링 맥박. 침묵 = 얇은 idle 링 (항상 얼굴에 붙어 있어야 함)
- 겹침 구간(21400ms) = 화자3+화자5 동시, 점선, 자막 「겹침」
- 얼굴 클릭 = 시선 고정, 해당 자막 우선
- 키보드 프리셋/입력 → 미리보기 오버레이 → 전송 시에만 grok-tts
- 스크립트 길이 SCRIPT_MS=41000. OVERLAP_MS=21400으로 점프 버튼 있음

STT/TTS (데모에서 실제로 쓰는 것)
- STT 벤치: xAI grok-stt language=ko. 실측 JSON src/data/asr-results.json
- TTS 발언: xAI grok-tts language=ko voice_id=eve. 사용자 제스처 후에만
- 회의 HUD의 자막은 아직 라이브 마이크가 아니다. meeting.ts 대본을 시계로 재생한다.
- 벤치 주의: 같은 벤더 TTS→STT 왕복은 천장(낙관). 원거리=잔향+핑크노이즈, 겹침=0.9초 믹스.
  근거리 ITN-CER 0%, CER 4.7%. 현장 글래스 마이크·다화자와는 다름.

사업계획 숫자 소스 = src/data/plan-v2.ts 하나. /plan이 이를 렌더한다.
artifacts에 보이스아이_사업계획서_v2.md / v1-v2_수정내역.md 가 없으면
plan-v2.ts를 원문으로 삼아 다시 써라. 추정 인용 11건은 미검증이라고 명시.

네비: src/components/AppNav.tsx — 회의 HUD / 사업계획 / 인식률
브랜드: src/lib/og/site.json title "보이스아이"

============================================================
```
