## 국비 합계가 항목 합과 어긋남

- 등급: 치명
- v1 기록: 12.0 + 3.0 + 8.4 + 4.8 + 3.0 = 31.2 ≠ 33.6
- v2: 12.0 + 3.0 + 9.6 + 3.0 + 3.3 + 1.5 = 32.4 = 32.4

재원 맵 국비 항목 합은 31.2억인데 합계는 33.6억이었다. “행안부·공공기관 자체 4.8”은 국비 칸이 아니어서 제외하면 격차가 7.2억이다. 어느 쪽으로 읽어도 표가 성립하지 않았다.

## 연차별 합계가 총사업비와 어긋남

- 등급: 치명

- v2: 6.0 + 16.0 + 28.0 = 50.0 = 50.0

같은 폭(2.4억)만큼 비어 있었다. 두 표가 동일 금액만큼 어긋난 것으로 보아 한 줄이 통째로 빠진 것으로 본다.

## 보급 목표 2,220대를 살 돈이 없었음

- 등급: 치명
- v1 기록: 필요 28.7억 > 배정 19.8억 — 약 9억 부족

## 하드웨어 전제가 사업을 인질로 잡고 있었음

- 등급: 치명
- v1 기록: 주 플랫폼 = Meta Ray-Ban Display / 국내 대안은 폴백
- v2: 주 플랫폼 = 노트북 연동 데스크형 투명 패널 / 글래스는 이동형 옵션

회의실 주 장치는 노트북 위에 두는 공유형 투명 자막 패널로 전환한다. 직접 투명 디스플레이와 광학 콤바이너 중 조달성·밝기·양면 가독성·안전성을 실측해 방식을 정하며, 개인 직구 예외를 국가 보급 근거로 사용하지 않는다.

## 생체정보 신원 매칭이 기본값이었음

- 등급: 치명
- v1 기록: 사전 등록 명단 + 얼굴·음성 임베딩 매칭 (기본)
- v2: 세션 한정 익명 화자 클러스터 + 주최자 수동 라벨링 (기본)

신원 식별용 얼굴·음성 임베딩은 개인정보 처리 검토 부담이 크므로 기본 경로에서 제외한다. 법적 분류와 동의 요건은 도입 전 검토한다. 기본값은 세션 한정 익명 화자이며 주최자가 수동으로 이름을 붙인다.

## 사용성의 핵심 지표가 아예 없었음

- 등급: 중대
- v1 기록: 지연 지표 없음 · WER 8% (측정조건 미기재)
- v2: 지연 0.8초 이하 · WER 12% (조건 명시) · DER 12% 병기

자막은 발화 종료 후 1초 안쪽에 떠야 대화에 붙는다. WER이 좋아도 지연이 2초면 회의 참여 수단으로 실패한다. 종단 지연을 지표표 최상단에 놓고, 방어 불가능했던 WER을 측정조건과 함께 현실화했다.

## v2 → v2.1 플랫폼 전환

사용자 결정에 따라 회의실 주 플랫폼을 스마트글래스에서 노트북 연동 데스크형 투명 패널로 전환했다. 글래스는 이동형 후속 옵션으로 내렸다. 패널은 확정 자막·발언자 위치를 공유하고, 비공개 발언 초안·수정·운영 설정은 노트북에만 둔다. 직접 투명 패널과 광학 콤바이너 중 밝기·양면 가독성·좌우반전·시야각·안전·KC·복수 견적을 통과한 방식을 채택한다. 이 전환은 기존 50.0억 재원표와 1,138,000원 키트 산술을 변경하지 않는다.

## P0에서 확인해 추가 교정한 사항

3. 미지원액 3.414억은 민간 총액의 일부로 명시했다. 3.41 = 3.4라는 등식을 제거하고 반올림 표기를 구분했다.
4. 계획서와 /plan은 동일 데이터의 검산표 여섯 항목을 사용한다. 문서 생성 후 --check로 최신 상태를 검증한다.
5. 실제 배경 이미지의 얼굴 위치가 전달문 좌표와 달라 meeting.ts의 head만 재보정했다. 링 크기와 44px 터치 영역을 분리하고 모바일 미니맵을 축소했다.

7. TTS 요청·재생 실패를 완료 자막으로 기록하던 오류를 수정했다. 편집하면 다시 미리보기가 필요하고, 중복 전송·네트워크 예외·화면 이탈 중 오디오를 처리한다.

9. /bench 원본 JSON은 수정하지 않았다. 과거 벤치 게이트와 v2 목표를 구분하고 현장 DER·스트리밍 지연 미측정을 명시했다.
10. Windows에서 npm 실행이 가능하도록 Vite JS 진입점을 사용하고, 추적되는 app-env.json으로 Auth OFF 기본값을 보존했다. DB는 도입하지 않았다.

- 지원율 80%·저소득 90%, 국비:지방 7:3은 미검증 가정이다. 보급 배정액 9.6:4.1을 정확한 7:3 집행비율로 단정하지 않는다. 미검증 인용 11건의 확인과 세부 배분 승인 전에는 제출 완료로 보지 않는다.

## 그대로 남은 제한

부록 인용 11건은 미검증이다. 라이브 ASR·익명 화자분리 실측·같은 방향 복수 화자 분리·패널 광학·KC 후보 검증은 후속 작업이며 이번 UI·문서 전환과 구분한다. 키 없는 TTS에서는 실패 경로만 검증할 수 있고 실제 음질·스피커 출력·현장 인식률을 확인했다고 주장하지 않는다.
