## 1. 사업 개요와 필요성

청각장애인 공유형 회의접근성 사업. 투명 공유 자막 · 발언자 위치 표시 · 누락 점검 회의기록 · 노트북 TTS 발언.

청각장애인이 공공·직장 회의에서 발언 내용을 읽고 발언자를 확인하며, 노트북으로 자신의 의사를 전달할 수 있도록 지원한다. 노트북 위 투명 패널을 통해 참석자의 얼굴과 몸짓을 보면서 확정 자막·화자 위치를 함께 확인한다. 비공개 발언 초안은 노트북에만 두고 확인한 문장만 패널과 스피커로 보낸다. 장애인 전용 외형을 강요하지 않으며 당사자 선호와 통역 선택권을 유지한다.

수어통역·문자통역을 보완하며, 노트북은 비공개 입력면·투명 패널은 공개 확인면으로 사용합니다.

총사업비 **50.0억** = 국비 **32.4억** + 지방 **8.0억** + 민간·수요 **9.6억**. 사업기간 **2028–2030**, 사전기획 2026.4Q–2027. 누적 보급 목표 **1,500세트**.

연계 협의 대상은 보건복지부 · 과기정통부 · 고용노동부 · 행정안전부 연계이며 부처의 지원 확약을 뜻하지 않는다. 실수요 1.5–2만명은 미검증 추정으로 모집·보급 타당성의 확정 근거가 아니다. 등록 인구·연령·경제활동 비율의 모집단 일치 여부와 회의 빈도를 사전기획 조사에서 확인한다.

## 2. 사용자 여정 및 현재 구현 범위

1. 듣기: 테이블 마이크 어레이가 음성을 수집하고 노트북이 한국어 전사와 익명 화자 분리를 수행한다. 확정 자막만 투명 패널 하단에 표시한다.
2. 보기: 패널 너머 참석자와 자막을 한 시야에서 본다. 좌석을 선택하면 해당 화자의 자막을 우선하며, 신뢰도가 낮으면 점선과 경고 문구를 함께 표시한다.
3. 함께 확인하기: 참석자도 공유 자막을 보고 오인식 표시를 누를 수 있다. 양면 표시의 좌우반전과 관찰각 문제는 하드웨어 후보별 실측 후 확정한다.
4. 말하기: 사용자는 노트북에서 문장을 작성하고 비공개 미리보기로 고친다. 확인 뒤에만 패널에 공개하고 탁상 스피커로 출력한다.
5. 남기기: 기본값은 비저장이다. 주최자가 참석자에게 고지하고 기록 모드를 켠 회의에서는 텍스트 저장을 기본으로 하며 음성·영상 저장은 별도 선택한다. 음성 감지 후 자막이 없는 구간, 겹침 발화, 저신뢰, 마이크 단절, 화자 미확정 이벤트를 타임라인에 남긴다. 회의 후 문제 구간을 재생·수정·확정하고 결정·담당자·기한을 원문 구간과 연결해 내보낸다.

현재 데모는 미리 작성한 회의 대본을 재생한다. 이름은 예시 명단이며 얼굴·음성 신원 매칭 결과가 아니다. 좌석 선택은 수동 자막 우선 기능이고, 얼굴 링은 단일 사용자 시점에서 보정된 위치 표시의 개념 예시다. 여러 관찰자에게 동시에 같은 얼굴 위치로 정렬된다고 주장하지 않는다. 실제 분리·실패 감지와 양면 광학 보정은 아직 미구현이다.

대본 기반 개념 시연 · 현재 마이크 수집·실시간 화자 인식·양면 광학 보정은 꺼져 있습니다.

자막은 이 화면의 메모리에 유지됩니다. 브라우저 STT는 공급자 서버로 음성을 전송할 수 있습니다. 시작 전 참석자에게 알려 주세요.

시연용 MVP: 브라우저 한국어 STT + 로컬 한국어 TTS · 기본 모드는 개발자 API 키·요금 없음 · 마이크 실측 및 faster-whisper·MeloTTS 연결은 미완료

기본 TTS는 기기에 설치된 한국어 음성을 사용합니다. 클라우드 모드를 별도로 설정한 경우에만 문장이 외부 음성 서비스로 전송됩니다.

로그인과 DB는 사용하지 않는다. LED는 실제 장치 도입 시 준수할 고지 요건이며 웹 데모가 하드웨어 LED를 제어한다는 뜻이 아니다. 화면의 참석자 확인면은 개념 시연이며 반대편 글자의 좌우반전·겹침·시야각은 실물 후보별로 검증한다.

## 3. 플랫폼·운영 전략

주 플랫폼은 노트북 위에 설치하는 데스크형 투명 자막 패널이다. 한 자리에서 참석자의 얼굴·몸짓과 자막을 함께 보고, 참석자도 같은 확정 자막을 확인하는 회의실용 장치로 정의한다.

테이블 마이크 → 노트북의 전사·화자분리 → 투명 패널의 공유 자막으로 연결한다. 발언 초안과 수정 화면은 노트북에만 두고, 확인한 문장만 패널과 스피커로 보낸다. 노트북은 기관 또는 사용자가 보유한 자산으로 가정해 키트 단가에서 제외한다.

구현 방식은 특정 패널 제품으로 고정하지 않는다. 직접 투명 OLED·LCD와 일반 디스플레이를 반투명 광학판에 반사하는 콤바이너 방식을 함께 비교하고, 밝기·대비·반사·양면 좌우반전·시야각·전도 안전·KC·조달 견적을 통과한 방식을 채택한다.

스마트글래스는 이동 중·현장 업무를 위한 후속 옵션이다. 국내 인증·유통·A/S와 화면 제어 API가 확인된 경우에만 같은 자막 렌더러를 연결하며, 회의실 보급의 선행조건으로 두지 않는다.

| 위험 | 왜 문제인가 | 검증 게이트 |
| --- | --- | --- |
| 밝기·대비 | 밝은 회의실에서 배경과 글자가 섞일 수 있음 | 조도 300/500/750lx에서 자막 판독률·오류시간 실측 |
| 양면 표시 | 반대편 글자가 좌우 반전되거나 겹쳐 보일 수 있음 | 단면 공유·보조 확인면·광학 구조를 후보별 비교 |
| 시야각·정렬 | 사용자가 움직이면 얼굴과 위치 표지가 어긋날 수 있음 | 초기형은 좌석 방향 표시, 후속형은 카메라 기반 시점 보정 |
| 안전·조달 | 패널 전도·모서리·인증·교체 부품 위험 | 무게중심·충격·KC·A/S·공식 견적을 보급 게이트로 설정 |

사업용 처리 목표는 국내 리전 또는 온프레미스이며 국외이전을 배제한다. 현재 xAI TTS 데모가 이 요건을 충족한다고 주장하지 않는다. 합성음 테스트와 현장 회의 실증을 구분하고 실증 전 데이터 흐름·보존·처리 지역·동의 요건을 확인한다.

## 7. 검산표 6항

| 검산 항목 | 계산·대조 | 결과 |
| --- | --- | --- |
| 국비 항목 합 | 12.0 + 3.0 + 9.6 + 3.0 + 3.3 + 1.5 = 32.4 | 통과 |
| 연차 합 = 총사업비 | 6.0 + 16.0 + 28.0 = 50.0 | 통과 |
| 보급대수 × 단가 × 지원율 | 1,500세트 × 1,138,000원 × 80% = 13.656억 ≤ 배정 13.7억 | 통과 |
| 국비 연차 합 = 국비 항목표 | 4.5 + 10.4 + 17.5 = 32.4 | 통과 |
| 지방비 연차 합 | 0.5 + 2.6 + 4.9 = 8.0 | 통과 |
| 민간 연차 합 | 1.0 + 3.0 + 5.6 = 9.6 | 통과 |

- 재원 총합: 32.4 + 8.0 + 9.6 = 50.0억. 확정된 교부금이 아닌 사업계획 편성안이다.
- 기기가액 총액 17.07억, 지원 소요 13.656억(소수 둘째 자리 반올림 13.66억), 배정 13.7억(국비 9.6 + 지방 4.1). 차액 0.044억 = 4,400,000원은 배정 여유이며 집행액이 아니다. 재원별 실제 집행 분담은 협의 후 확정한다.
- 미지원 20% 3.414억(반올림 3.41억)은 사용자·고용주·수요기관 분담 가정이며 민간 총액 9.6억 안에 포함한다. 기존 표시 3.4억은 정확한 필요액보다 0.014억 적으므로 동일 금액이라는 등식을 제거했다. 민간 잔여액은 6.186억이다.
- 설치·적합·훈련 소요: 1,500세트 × 120,000원 = 1.8억. 지방 총액 8.0억 중 보급 배정 4.1억과 설치·훈련 1.8억을 제외한 2.1억의 세부 집행 내역은 제출 전 확정한다.
- 지원율 80%·저소득 90%, 국비:지방 7:3은 미검증 가정이다. 보급 배정액 9.6:4.1을 정확한 7:3 집행비율로 단정하지 않는다. 미검증 인용 11건의 확인과 세부 배분 승인 전에는 제출 완료로 보지 않는다.

검산 통과는 산술 및 배정 한도 확인이며 정책 근거·재원 확약·조달 단가 검증 완료를 의미하지 않는다. 국비 보급 9.6억은 국비 총액의 일부, 지방 보급 4.1억은 지방 총액의 일부, 미지원분 3.414억은 민간 총액의 일부다. 부담 주체는 사용자·고용주·수요기관 협의로 정하며 같은 금액을 추가로 총사업비에 더하지 않는다.

## 9. 유지할 결정

- 회의실 보급의 주 플랫폼은 노트북 연동 데스크형 투명 패널로 둔다. 스마트글래스는 국내 인증·유통·화면 제어가 확인된 이동형 옵션으로만 검토한다.
- 비공개 발언 초안은 노트북에만 표시하고, 사용자가 확인한 문장만 공유 패널과 스피커로 보낸다.
- 생체정보 신원 매칭을 기본값으로 되돌리지 않는다. 기본은 세션 한정 익명 클러스터 + 주최자 수동 라벨링이며 법적 요건은 도입 전 검토한다.
- 기록 모드는 참석자 고지 후에만 켠다. 기록 모드 안에서는 텍스트 저장을 기본으로 하고 음성·영상 저장은 별도 선택하며, 보관기간과 삭제 예정일을 회의 시작 전에 표시한다.
- 특정 제품명을 품질 기준으로 쓰지 않는다. 조달 공정성 시비와 자기모순을 동시에 부른다. 객관 지표로만 적는다.
- “예타를 피하는 규모”라는 표현을 쓰지 않는다. 사업 쪼개기 의심을 자초한다.
- 숫자를 고칠 때는 검산표 여섯 항목을 다시 맞춘다. v1이 죽은 이유가 정확히 이 검산 실패였다.
